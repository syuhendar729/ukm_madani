# Checklist Revisi UI/UX - UKM Madani

Sumber: `ITERA Madani - UI-UX Auditing.pdf`, 28 September 2026.

## P1 - Dikerjakan

- [x] Aksi Kontak kini menuju blok kontak yang nyata pada beranda.
- [x] Form Kritik & Saran dipindahkan dari Infaq ke Kontak.
- [x] Infaq difokuskan ke rekening, langkah verifikasi, dan kontak konfirmasi.
- [x] Placeholder QRIS yang menyesatkan dihapus; status QRIS menunggu aset yang tervalidasi.
- [x] Navigasi mobile dibuat menutupi lebar layar penuh, dengan overlay dan tombol tutup yang tetap ada.
- [x] Kontras item navigasi mobile diperkuat; state aktif tetap terlihat tanpa memudarkan item lain.
- [x] Sidebar detail Artikel/Berita ditempatkan setelah isi pada layar tablet dan mobile.
- [x] Overflow horizontal dicegah untuk konten, media, tabel, dan iframe.
- [x] Kartu daftar Artikel dan Berita dibuat menjadi satu tautan yang dapat difokuskan dengan keyboard.
- [x] Breadcrumb menandai tautan leluhur secara konsisten dan halaman aktif bukan tautan.
- [x] Kontak di footer menjadi aksi langsung untuk telepon dan email.

## P2 - Dikerjakan

- [x] Kontrol kategori dan Filter diseragamkan tinggi serta baseline-nya.
- [x] Deskripsi galeri dipadatkan agar beberapa kartu lebih mudah dipindai.
- [x] Footer mobile disingkat dengan menyembunyikan daftar program panjang.
- [x] WhatsApp floating action akan tersembunyi ketika modal profil terbuka.

## Perlu konfirmasi / aset dari pengelola

- [ ] QRIS resmi yang aktif belum tersedia di proyek; unggah atau kirim file QRIS dan nama penerimanya agar dapat ditampilkan serta diuji.
- [ ] Nomor WhatsApp, nomor rekening, nama penerima, jam layanan, dan email perlu dikonfirmasi sebelum rilis.
- [ ] Penyatuan header/footer seluruh halaman dan pemadatan total struktur organisasi perlu keputusan konten karena beberapa template lama memakai markup berbeda.
- [ ] Teks placeholder pada entri Galeri tersimpan di basis data; perlu dibersihkan dari panel admin/data produksi.
